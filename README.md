# Maksim Iurchenko — Multi-page Portfolio

A responsive static website for GitHub Pages. It includes:
- `index.html` — home
- `about.html` — profile and working principles
- `experience.html` — professional timeline
- `education.html` — degrees, thesis and certificates
- `research.html` — hyperspectral imaging and research software
- `marginum.html` — signal-processing experience
- `craif.html` — medical imaging and AI-related research work
- `skills.html` — technical toolkit
- `contact.html` — contact links
- `style.css` — shared responsive design

## Publish with GitHub Pages
1. Download and unzip this package.
2. Review every page and correct any details that need updating.
3. Add your professional photo if desired. The home page currently uses a designed placeholder; no image is required for the site to work.
4. Upload the files to the root of the GitHub repository used for your portfolio.
5. In GitHub, open **Settings → Pages**, choose the branch and `/ (root)` folder, and save.
6. If using a custom domain, preserve your existing domain settings and `CNAME` file (if present).

## Important before public release
- Verify dates, official titles, and any company names.
- Confirm that employer/client work and project descriptions can be shared publicly.
- Add only approved screenshots, source repositories, thesis links or measurable results.
- The descriptions of medical imaging work are research-oriented and do not claim a clinically validated diagnostic product.
- No contact form or backend is used; the email link opens the visitor's email application.
