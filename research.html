04 / SIGNAL PROCESSING

Sensor data, peak detection & classification

Signal-processing workflows designed to extract meaningful events from noisy, high-frequency measurements.

Marginum · Data Specialist · 2023–2024

Peak detection and event classification

Developed a signal-processing pipeline for noisy sensor data. The workflow used Savitzky–Golay smoothing, dynamic baseline detection and SciPy peak detection, followed by amplitude-based classification of events into Tissue, Cancer and Water categories.

The project description reports tests on high-frequency data sampled at 50,000 samples per second and classification accuracy above 98% on the evaluated dataset. The work also examined limitations such as fixed thresholds, closely spaced peaks and single-channel analysis.

HOW THE WORK CONNECTS

One engineering approach across different domains

Across these projects, the common thread is turning a practical problem into a measurable, testable workflow.

1. Understand the physical problemMaterials, machine behaviour, medical images, sensor signals or production requirements.
2. Capture and prepare dataImaging, calibration, filtering, segmentation, ROI selection and data validation.
3. Build the software or control logicPython tools, neural networks, signal pipelines, CNC programs or embedded controllers.
4. Evaluate in contextVisualise outputs, check measurements and test whether the solution works for the real task.
